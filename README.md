PERSONAL EXPENSES DASHBOARD

Project Description
This project analyzes personal expenses using Excel, Oracle SQL and Power BI.

Tools Used
1. Microsoft Excel
2. Oracle Database 10g
3. SQL
4. Power BI
5. Power Query
6. DAX

Dataset
The dataset contains 30 personal expense transactions.

Categories
- Food
- Transport
- Bills
- Shopping
- Entertainment
- Health

Payment Methods
- UPI
- Cash
- Card

Oracle Database
The EXPENSES table was created in Oracle Database 10g.

SQL Work
- Created EXPENSES table
- Created sequence
- Created trigger
- Inserted expense data
- Validated the data
- Performed SQL analysis

Power BI Work
- Connected Power BI to Oracle
- Imported EXPENSES table
- Created DAX measures
- Created KPI cards
- Created charts
- Created slicers
- Created interactive dashboard
